# Base de juego de pelea

Esta es una base simple de un juego de pelea estilo `Super Smash Bros` / `Street Fighter` usando HTML, CSS y JavaScript.

## Cómo usar

1. Abre `index.html` en un navegador.
2. Usa los controles para mover a los dos luchadores.

## Controles

- Jugador 1: `A` / `D` para moverse, `W` para saltar, `S` para atacar
- Jugador 2: `←` / `→` para moverse, `↑` para saltar, `↓` para atacar

## Qué incluye

- Motor de movimiento básico con gravedad
- Golpes con área de ataque
- Barra de vida básica
- Detección de colisiones y ganador
